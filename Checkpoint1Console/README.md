## Projeto Console

Faça um Programa em linguagem C# do tipo Console no Visual Studio 2022, para calcular a idade de uma pessoa, que deve inserir via Console o nome completo
e a data de nascimento, e com estas entradas de dados, o programa deve calcular a idade com base na data atual do Sistema Operacional (SO) e retornar esse valor inteiro para o usuário que solicitou a informação via Console.

    – Deve-se usar Struct obrigatoriamente na construção deste projeto.
    – Além disso, o programa deve informar se o usuário é maior de idade e se pode realizar o procedimento para tirar a carteira de habilitação para dirigir, informando também via Console.
